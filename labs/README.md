# RampLab challenge catalogue

All exercises are designed for a local synthetic environment. Do not test these routes against systems you do not own or have explicit permission to assess.

| ID | Challenge | Level | Primary learning objective |
|---|---|---|---|
| RAMP-001 | Broken object-level authorization | Beginner | Enforce ownership at the API object boundary |
| RAMP-002 | Caller-controlled exchange rate | Intermediate | Keep financial pricing authoritative on the server |
| RAMP-003 | Unsigned/replayable payment callback | Intermediate | Authenticate callbacks and enforce idempotency |
| RAMP-004 | Smart-contract reentrancy | Intermediate | Apply checks-effects-interactions and reentrancy protection |
| RAMP-005 | Unauthorised fiat-deposit confirmation | Intermediate | Enforce the payment-provider trust boundary before minting |

## Learning modes

- **Guided:** complete walkthroughs and questions are in `guided/`.
- **Independent:** concise briefs without exploit instructions are in `independent/`. Learners document their findings before reviewing the guided material.

The dashboard includes a mode selector that hides the embedded guidance content in independent mode. A future iteration will load full challenge briefs, hints and scoring from versioned challenge metadata.
